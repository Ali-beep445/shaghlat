# شغلات | SHAGHLAT

سوق إلكتروني عراقي متعدد المحافظات — نسخة أولية مبنية باستخدام Expo وReact Native.

## ما الموجود في هذه النسخة؟
- واجهة عربية واتجاه من اليمين إلى اليسار.
- أقسام للمنتجات والبحث حسب الاسم/المدينة.
- نموذج تجريبي لإضافة المنتجات من شاشة الإدارة.
- العملة: الدينار العراقي.

## مهم قبل الإطلاق
هذه نسخة واجهة أولية. المنتجات تُحفظ مؤقتاً في ذاكرة التطبيق ولا تتم مزامنتها بين الأجهزة. شاشة الإدارة ليست محمية بعد. قبل نشر التطبيق يجب إضافة:
1. تسجيل دخول إداري آمن بصلاحيات من الخادم.
2. قاعدة بيانات وتخزين صور المنتجات.
3. سياسات نسخ احتياطي وحماية وإدارة محتوى.

## التشغيل
يتطلب Node.js 22.13 أو أحدث وبيئة Expo SDK 58:
```bash
npm install
npx expo start
```

## بناء APK لاحقاً
بعد ضبط مشروع Expo وربط حساب EAS، نضيف إعدادات البناء السحابي ونبني نسخة Android APK.
